## 视觉基准

- 物种：原创圆润团子兽，不是普通猫、狗、兔、熊或狐狸。
- 轮廓：梨形圆身、低重心、头身一体、极短圆肢、两枚圆耳突。
- 五官：深可可色小椭圆眼，位置偏低且间距固定；浅 `w` 形小嘴；无口鼻凸起。
- 星灵特征：额头中央单枚暖金五角星；短粗彗尾末端连接单枚发光星。
- 光源：统一为左上方暖光。
- 脚底锚点：目标为画布归一化坐标 `(0.5, 0.92)`。
