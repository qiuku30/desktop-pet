## 一、模块定位

单词模块是桌宠的第三个游戏化模块（继番茄钟、2048 之后）。定位为：

- **半正经半摸鱼**：有系统化的 SRS 学习体系，但节奏完全用户自己控制
- **与宠物深度联动**：宠物感知学习状态，提供复习提醒、情感反馈，词汇量影响宠物成长

---

## 二、学习模式

### 2.1 新词学习

- 用户从选中的词库中取未学的新词
- 卡片正面展示单词（只有拼写），鼓励用户脑中回忆
- 点击翻卡 → 展示完整信息（音标、释义、例句、⭐收藏按钮）
- 用户自评：[记住了] / [不太熟]
- 自评后进入 FSRS 调度，安排第一次复习时间
- 一组学完后弹窗：[继续学下一组] [去复习] [今天就到这]

### 2.2 复习

- FSRS 判定到期的词进入复习队列
- 新词（稳定性低）→ 选择题（4 选 1，看英文选中文释义）
- 熟词（稳定性高）→ 填空题（给中文释义，拼写英文）
- 先展示单词（不展示选项）→ 用户点击 → 展示选项
- 选项包括"忘记了，看答案"，防止蒙对
- 填空题有"暂时跳过填空题"（30 分钟冷却）
- 一组复习完后弹窗：[继续复习] [去学新词] [今天就到这]

### 2.3 入口

- 📋 复习（独立入口，用户随时进）
- 📖 学新词（独立入口，用户随时进）
- 首页显示今日进度和待复习数量

## 三、单词本

### 3.1 结构

```
📖 单词本
├── 🔍 全局搜索（搜索所有词库 + 已学词）
├── 我的
│   ├── 📝 我的单词本（所有已学过的词）
│   └── ⭐ 我的收藏（已学词中标记了收藏的）
├── 词库
│   ├── 📗 CET-4（显示已学/总数进度）
│   ├── 📘 CET-6
│   ├── 📙 考研
│   ├── 📕 雅思
│   └── 📓 TOEFL
```

### 3.2 单词列表页

- 按字母分组（A-Z），右侧字母索引快速跳转
- 筛选：全部 / 已学 / 未学（我的单词本则筛选：全部 / 收藏 / 最近学习）
- 每个词显示：拼写、释义、✅已学标记、⭐收藏标记
- 词库内搜索框（type-ahead 实时过滤）
- 点击单词 → 进入详情卡片

### 3.3 单词详情卡片

- 完整信息：拼写、音标、释义（所有词性）、例句（含中文翻译）
- 来源词库
- 学习状态标记
- ⭐ 收藏/取消收藏
- 🔄 重新学习（清除 FSRS 数据，下次当新词重新学）

### 3.4 搜索

- 单词本主页：全局搜索，跨所有词库 + 已学词
- 词库列表页：词库内搜索
- type-ahead 自动补全，毫秒级过滤
- 每个结果展示：单词、释义、来源词库、学习状态

---

## 四、SRS 算法

- 采用 **FSRS**（Free Spaced Repetition Scheduler）
- 冷启动使用默认参数，积累足够 review 数据后自动拟合参数
- 用户每次复习评分：Good（选对）/ Again（选错或点"忘了"）
- 新词学习后进入 FSRS 调度安排首次复习

## 五、设置

| 设置项 | 默认值 | 范围 | 存储位置 |
|--------|--------|------|----------|
| 启用的词库 | [CET-4] | 多选 | wordProgress.settings.selectedBanks |
| 每日新词上限 | 10 | 1-50 | wordProgress.settings.dailyNewWordsLimit |
| 每组学习数量 | 10 | 5-30 | wordProgress.settings.learnGroupSize |
| 每组复习数量 | 15 | 5-50 | wordProgress.settings.reviewGroupSize |

---

## 六、宠物联动（Phase 2）

| 触发条件 | 宠物反应 |
|----------|----------|
| 有到期未复习的单词 | 宠物态气泡提醒（类似番茄提醒） |
| 完成今日所有复习 | 宠物开心动画 + 气泡 |
| 连续 N 天打卡 | 鼓励台词 |
| 长期未学（>3 天） | 宠物 sad 动画 + 气泡 |
| 累计词汇量达到里程碑（100/200/500...） | 宠物特殊动画/外观变化 |

- 宠物态只做提醒 + 情感反馈，不做交互式学习
- 真正的学习动作在面板态完成

## 七、数据结构

### 7.1 PetState 新增字段

```js
wordProgress: {
  settings: {
    dailyNewWordsLimit: 10,
    learnGroupSize: 10,
    reviewGroupSize: 15,
    selectedBanks: ["cet4"],
    fillInBlankCooldownUntil: null
  },
  streak: {
    current: 5,
    lastStudyDate: "2026-08-04"
  },
  words: {
    "abandon": {
      // FSRS 状态
      stability: 2.5,
      difficulty: 0.3,
      state: "review",       // "new" | "learning" | "review" | "relearning"
      lastReview: "2026-08-04T10:30:00Z",
      due: "2026-08-06T10:30:00Z",
      reps: 3,
      lapses: 0,
      // 用户标记
      isFavorited: false,
      sourceBank: "cet4"
    }
    // ...
  }
}
```

### 7.2 词库数据

- ECDICT（开源英中词典）SQLite → 主进程 `better-sqlite3` 查询
- 词库索引文件（只存词条 ID 列表）：`assets/word-banks/cet4.json` 等
- `ecdict.db` 打包为 `extraResources`

### 7.3 词库索引格式

```json
{
  "name": "CET-4",
  "version": "1.0",
  "count": 4500,
  "words": ["abandon", "ability", "abroad", "..."]
}
```

## 八、IPC 通道（新增）

| 通道 | 方向 | 参数 | 返回 |
|------|------|------|------|
| `word:lookup` | renderer → main | `word: string` | 完整词条对象 |
| `word:batch-lookup` | renderer → main | `words: string[]` | 词条对象数组 |
| `word:choices` | renderer → main | `correct: string, count: number` | 随机干扰词条数组 |

---

## 九、EventBus 事件（新增）

| 事件 | payload | 触发时机 |
|------|---------|----------|
| `word:learned` | `{ word }` | 学完一个新词 |
| `word:reviewed` | `{ word, rating }` | 完成一次复习 |
| `word:streak:changed` | `{ current }` | 连续天数变化 |
| `word:milestone` | `{ total, milestone }` | 达到词汇量里程碑 |
